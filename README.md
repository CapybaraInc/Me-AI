# 🎭 AI Poet & Songwriter

Нейросеть для генерации стихов и песен прямо в браузере телефона. 
Работает офлайн после первой загрузки.

## ✨ Возможности

- 📝 Стихи в стиле: Пушкин, Есенин, Ахматова, Маяковский
- 🎵 Тексты песен: поп, рок, рэп, народные
- 📱 PWA — можно установить на телефон
- 🔒 Приватность — всё работает локально

## 🚀 Запуск

1. Клонируйте репозиторий
2. Откройте `index.html` в браузере
3. Или захостите на GitHub Pages

## 🛠 Технологии

- Transformers.js (модели в браузере)
- PWA (Service Worker)
- Vanilla JS
